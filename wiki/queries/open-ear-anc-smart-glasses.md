## TL;DR

开放式智能眼镜因不密封耳道，无法使用传统 ANC 所需的耳内误差麦克风。本文提出**虚拟耳内感知（Virtual In-ear Sensing）**：用眼镜框上的 8 个 MEMS 麦克风输入神经网络，直接估计每个麦克风到耳道的 ANC 滤波器系数，无需耳内麦克风。系统采用**双流水线架构**——CPU 上的神经网络每 200ms 更新滤波器，超低延迟 DSP 以 113µs 端到端延迟实时生成反噪声。在 8 种真实环境、11 名用户测试中，无需校准平均降噪 **9.6 dB**，经 10 秒用户校准后达 **11.2 dB**。

## 论文概述

**问题**：开放式眼镜没有耳道密封，传统 ANC 依赖的耳内误差麦克风无法安装，导致开放式设备长期缺乏有效的主动降噪方案

**方案**：利用眼镜刚性框架提供的固定空间几何关系，用神经网络从框上麦克风信号中"虚拟"估计耳道处的声学信号和最优 ANC 滤波器

**贡献**：
1. 首个在真实环境中运行的开放式眼镜 ANC 系统，无需耳内误差麦克风
2. 虚拟耳内感知：U-Net + LSTM + FiLM 架构，从 8 通道麦克风估计 4 通道 2048-tap FIR 滤波器
3. 混合混合卷积 DSP：前端时域 256-tap 直接卷积 + 后端频域分块卷积，113µs 端到端延迟
4. 8 环境 × 11 用户真实测试：无校准 9.6 dB，校准后 11.2 dB（100-1000 Hz）

## 背景与动机

### 开放式 ANC 的核心矛盾

传统 ANC（耳机/耳塞）的工作流程：

```
环境噪声 → 参考麦克风 → ANC 滤波器 → 扬声器 → 耳道
                                    ↓
                         误差麦克风（耳内）→ 自适应更新滤波器
```

误差麦克风测量抵消后的残余噪声，提供自适应算法所需的**反馈信号**。没有它，FxLMS 等算法无法计算梯度。

开放式眼镜的问题在于：
1. **无耳道密封** → 无法在耳道内放置误差麦克风
2. **开放声路** → 环境噪声直接进入耳道，不经过任何传感器
3. **个体差异大** → 头型、耳形、眼镜佩戴位置影响声学传递函数

### 关键洞察

智能眼镜的刚性框架在麦克风与耳道之间建立了**近似固定的空间关系**。噪声绕射头部时，在框上各麦克风与耳道处产生的测量值是**相关的**——如果知道框架的几何结构和声学传播模型，就可以从框上麦克风推断耳道处的信号。

## 核心方法

### 整体架构

```
8 通道框上麦克风 (22050 Hz)
    ↓
降采样至 8820 Hz → STFT → IPD/ILD/参考频谱 (11 通道)
    ↓
U-Net 编码器 → SE 块 → LSTM 瓶颈层 → FiLM 调制 (二次路径)
    ↓
频域滤波器 (8 通道) → 时域整形 → IFFT → 2048-tap FIR × 4 通道
    ↓
UDP 发送至 DSP → 混合分块卷积 → 反噪声信号 (113µs 端到端)
```

两侧独立：每侧 4 麦克风 + 1 扬声器，各自估计 4 个滤波器。

### 虚拟耳内感知：神经网络

**输入特征**（从 STFT 提取，共 11 通道）：
- **参考频谱** (2 通道)：离扬声器最近麦克风的实部 + 虚部
- **通道间相位差 IPD** (6 通道)：3 个非参考麦克风相对于参考的 sin/cos 相位差
- **通道间强度差 ILD** (3 通道)：3 个非参考麦克风相对于参考的声级差

$$\text{IPD}_m(t, f) = [\sin(\angle X_\text{ref} - \angle X_m), \cos(\angle X_\text{ref} - \angle X_m)]$$

$$\text{ILD}_m(t, f) = \log_{10}\frac{|X_\text{ref}| + \epsilon}{|X_m| + \epsilon}$$

IPD 和 ILD 编码了噪声源与头部的**空间几何关系**——这是神经网络能推断耳道信号的关键线索。

**网络结构**：

| 组件 | 配置 |
|------|------|
| 编码器 | 7 层 Conv2d，通道数 [32, 64, 64, 128, 128, 256, 256]，kernel (5,2)，stride (2,1) |
| SE 块 | 压缩比 4，全局平均池化 + 两层 FC + sigmoid 门 |
| 瓶颈层 | 单向 LSTM，hidden size 128 |
| 解码器 | 7 层转置卷积，镜像编码器 |
| 输出 | 2M = 8 通道（4 麦克风 × 实/虚部）频域滤波器 |
| 参数量 | 4.2M，5.3G MACs/次推理 |

### 二次路径调节：FiLM 层

二次路径 $s[n]$（扬声器到耳道的声-电链路）因人而异。系统支持两种模式：

| 模式 | 方法 | 性能 |
|------|------|------|
| **无校准** | 使用训练集平均二次路径 | 9.6 dB |
| **有校准** | 10 秒 ESS 信号 + 临时耳内麦克风 | 11.2 dB |

校准得到的 1024-tap 脉冲响应经过 FFT → 513 频点 → MLP 压缩为 128 维嵌入 → **FiLM 层**调制 LSTM 瓶颈特征：$\gamma \odot h + \beta$。好处是不需要重新训练模型。

### 损失函数

$$\mathcal{L} = \|e[n]\|_1 = \|d[n] + \hat{d}[n]\|_1$$

关键点：损失直接优化**耳道残余噪声**，而不是让网络去"重建"耳道信号。网络学习的是"什么滤波器能最小化残余"，而不是"耳道信号长什么样"。

### 实时反噪声生成：混合分块卷积

```
2048-tap 滤波器
├── Head: 前 256-tap → 时域直接卷积（实时音频线程，45µs/样本硬上限）
└── Tail: 剩余 1792-tap → 频域分块卷积（后台线程）
    ├── 每 128 样本做 FFT
    ├── 与预计算的滤波器分块频域响应相乘
    ├── IFFT + 重叠相加
    └── 与 Head 输出相加 → 最终反噪声
```

实测：中位处理延迟 38µs（45µs 硬上限内），端到端 113µs。

### 声反馈消除 (AFC)

$$x_m[n] = x'_m[n] - (y[n-1] * \hat{g}_m[n])$$

从原始麦克风信号中减去估计的扬声器→麦克风泄漏，得到干净的环境噪声。

## 深度理解问答

### Q1: 为什么开放式 ANC 不能用传统 FxlMS？

FxlMS 的更新规则需要误差信号 $e[n]$ 来计算梯度。开放式眼镜耳道是开放的，$e[n]$ 无法物理测量。本文的解决思路：不实时计算梯度，而是让神经网络**一次性输出最优滤波器**。推理阶段只需要框上麦克风——滤波器是直接估计的，不需要反馈循环。

### Q2: 为什么用频域输出而不是时域输出？

1. **频域更平滑**：声学传递函数的频域响应比时域脉冲响应更光滑
2. **物理约束自然**：频域整形可以在频域直接操作
3. **计算效率**：U-Net 的空间下采样在频域维度更高效

### Q3: FiLM 层为什么比微调整个网络更好？

FiLM 只注入 128 维仿射参数 $(\gamma, \beta)$ ≈ 512 字节/用户。全量微调 4.2M 参数 ≈ 16 MB/用户。FiLM 在不需要存储大量参数的情况下实现了用户自适应。

### Q4: 200ms 更新间隔够用吗？

对于 100-1000 Hz 的环境噪声，200ms 内声学场景变化相对缓慢。但对于脉冲噪声（关门声），200ms 内的滤波器可能不是最优的。改进方向：增量推理、专用 NPU、SoC 集成消除 UDP 开销。

### Q5: 室外性能下降 1.8 dB 的原因？

**风噪声 vs 声学噪声**的物理区别：
- 声学噪声：压力波传播 → 框上麦克风与耳道处的信号**相关** → 可预测
- 风噪声：湍流直接冲击麦克风振膜 → 产生**不相关**的压力波动 → 不可预测

## 总结

### 核心贡献
- 证明了无需耳内麦克风也能实现有效的开放式 ANC
- 虚拟耳内感知 + 双流水线架构满足了实时性要求
- 在真实环境和真实用户上验证了泛化能力

### 局限性
- 户外风噪场景性能下降（9.5 dB vs 11.3 dB 室内）
- 200ms 滤波器更新率对快速声学变化响应不足
- 双开发板原型功耗 5-7W，集成 SoC 才能实用
- 校准仍需 10 秒临时耳内麦克风

### 延伸思考
- **AR/VR 头显迁移**：更大机身，麦克风间距更远，某些声源方向"前瞻"更多，理论上可能更强降噪
- **语义选择性 ANC**：结合 ASR + 语义理解，保留想听的声音、抑制不想要的
- **少麦克风部署**：2 麦克风仍有 8.9 dB，Ray-Ban Meta 只有 5 麦克风，可直接部署
