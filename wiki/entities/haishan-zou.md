# Haishan Zou

**Affiliation**: Key Laboratory of Modern Acoustics, Institute of Acoustics, Nanjing University, Nanjing, China
**Role**: Researcher
**Research Focus**: Active noise control, multi-reference ANC, neural reference projection.

## Key Contributions

- Co-author of "Neural Projection Filter Generation for Multi-Reference Active Noise Control" (IEEE Signal Processing Letters 2026) — condition-aware projection filtering (CAPF) that generates block-wise FIR projection filters for reference compression — [[sources/he-2026-neural-projection-filter-anc|He et al. 2026]]
- Co-author of "Causal Reference-Enhanced Keep-Speech Active Noise Control" (Interspeech 2026, Sydney, Australia, pp. 4966–4970, 2026) — causal WaveNet-based reference enhancement for keep-speech ANC with a conventional FIR control filter — [[sources/rao-2026-keep-speech-anc|Rao, Rong, Sun, He, Chen, Zou & Lu 2026]]
