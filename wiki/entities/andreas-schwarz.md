# Andreas Schwarz

Researcher in dereverberation and robust speech recognition using spatial coherence models.

## Affiliation

- Friedrich-Alexander-Universität Erlangen-Nürnberg (FAU)

## Research Areas

- Spatial coherence modeling for reverberation
- Spectral enhancement using coherence-to-diffuse ratio (CDR)
- Reverberation-robust automatic speech recognition
- Multichannel signal processing

## Key Contributions

- Proposed a dereverberation system operating without source position knowledge, solely exploiting spatial coherence of reverberation
- Introduced spatial feature vectors from short-time coherence estimates as DNN input for robust ASR
- Unified existing spectral enhancement methods within a CDR framework and proposed novel estimators
