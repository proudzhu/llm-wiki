# Kouei Yamaoka

**Affiliation**: The University of Tokyo, Japan
**Role**: Researcher
**Research Focus**: Blind source separation, distributed microphone arrays, independent vector analysis.

## Key Contributions

- Co-authored Distributed FastMNMF with block-diagonal SCMs for distributed microphone arrays (arXiv 2026)
- Auxiliary-function-based decentralized independent vector analysis for distributed microphone arrays (APSIPA ASC 2025)
- First author of "TF-Bin-Wise Linear Combination of Beamformers" (IEEE/ACM TASLP 2021, TAF Telecom System Technology Student Award) — TFLC/RTFLC beamforming framework for distortionless enhancement in underdetermined situations — [[sources/yamaoka-2021-bin-wise-beamformer-combination|Yamaoka, Ono & Makino 2021]]
