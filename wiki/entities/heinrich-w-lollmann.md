# Heinrich W. Löllmann

**Affiliation**: Friedrich-Alexander-Universität Erlangen-Nürnberg (FAU), Chair of Multimedia Communications and Signal Processing
**Role**: Researcher
**Research Focus**: Multichannel speech enhancement, coherence-based signal processing, CDR estimation, hearing aid signal processing.

## Key Contributions

- Generalized coherence-based CDR estimation using eigenvalue decomposition of the multi-microphone coherence matrix (ICASSP 2020)
- Binaural signal enhancement for hearing aids using generalized magnitude coherence
