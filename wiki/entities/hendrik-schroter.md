# Hendrik Schröter

**Affiliation**: Friedrich-Alexander-Universität Erlangen-Nürnberg, Pattern Recognition Lab, Erlangen, Germany
**Role**: Researcher
**Research Focus**: Speech enhancement, deep filtering, low-complexity neural networks for audio processing.

## Key Contributions

- Lead author of [[sources/schroter-2022-deepfilternet|DeepFilterNet]] — low-complexity speech enhancement framework using deep filtering (ICASSP 2022)
- Co-author of DeepFilterNet2 — real-time speech enhancement on embedded devices
- CLCNet — deep learning-based noise reduction for hearing aids using complex linear coding (ICASSP 2020)
- Lightweight online noise reduction using hierarchical RNNs (INTERSPEECH 2020)
