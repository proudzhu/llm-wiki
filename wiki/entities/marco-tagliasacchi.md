# Marco Tagliasacchi

**Affiliation**: Google Research
**Role**: Research Scientist
**Research Focus**: Speech enhancement, multi-modal learning, audio signal processing, machine learning.

## Key Contributions

- **SEANet** (INTERSPEECH 2020) — First multi-modal speech enhancement network using accelerometer data from earbuds; wave-to-wave UNet with adversarial + feature losses, achieving 9.6 dB SI-SDRi in mixed-speech scenarios.
