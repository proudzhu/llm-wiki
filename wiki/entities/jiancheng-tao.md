# Jiancheng Tao

**Affiliation**: Key Laboratory of Modern Acoustics, Institute of Acoustics, Nanjing University, Nanjing, China
**Role**: Researcher
**Research Focus**: Active noise control, multi-reference ANC, adaptive filtering.

## Key Contributions

- Co-author of "Neural Projection Filter Generation for Multi-Reference Active Noise Control" (IEEE Signal Processing Letters 2026) — condition-aware projection filtering (CAPF) that generates block-wise FIR projection filters for reference compression — [[sources/he-2026-neural-projection-filter-anc|He et al. 2026]]
- Co-author of "A neural reference projection-based method for multi-reference active noise control (L)" (J. Acoust. Soc. Am. 2026, vol. 159(5), pp. 4482–4486) — neural reference projection for multi-reference ANC
- Co-author of "A modified least mean square Newton algorithm based on block coordinate descent for multi-reference active noise control" (J. Acoust. Soc. Am. 2025, vol. 158(3), pp. 2377–2388) — modified LMS-Newton via block coordinate descent
