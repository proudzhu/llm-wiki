# Andy W. H. Khong

**Affiliation**: Nanyang Technological University, Singapore
**Role**: Researcher / professor
**Research Focus**: Adaptive filtering for sparse system identification and network echo control, speech enhancement, bandwidth extension, and real-time neural packet loss concealment.

## Key Contributions

- Co-authored "Improving performance of real-time full-band blind packet-loss concealment with predictive network" (ICASSP 2023) — the full-band recurrent network (FRN) for blind 48 kHz PLC, developed with the Crystalsound team (NamiTech JSC) — [[sources/nguyen-2023-predictive-plc|Nguyen, Nguyen & Khong 2023]]
- Co-authored "TUNet: A block-online bandwidth extension model based on transformers and self-supervised pretraining" (ICASSP 2022) — transformer-based bandwidth extension with self-supervised pretraining
- Co-authored "A low delay and fast converging improved proportionate algorithm for sparse system identification" (EURASIP J. Audio, Speech, and Music Processing 2007) — proportionate adaptive filtering for sparse (network echo) systems, cited by the FRN paper among VoIP echo problems
- Co-authored "Frequency domain selective tap adaptive algorithms for sparse system identification" (ICASSP 2008) — selective-tap frequency-domain adaptive filtering
