# Yoshinobu Kajikawa

**Affiliation**: Kansai University, Japan
**Role**: Professor
**Research Focus**: Active noise control, adaptive signal processing, audio systems.

## Key Contributions

- Co-authored hybrid ANC system for remote microphone based virtual sensing with two compensation filters (ICASSP 2026)
- First author of "Active Noise Control Without a Secondary Path Model by Using a Frequency-Domain Simultaneous Perturbation Method With Variable Perturbation" (ICASSP 2003) — FDSP with perturbation magnitude scaling with error power: ~75× larger step size than fixed perturbation, ~3× cheaper than FxLMS, fast recovery after secondary-path change — [[sources/kajikawa-2003-fdsp-variable-perturbation|Kajikawa & Nomura 2003]]
