# Jonas Forster

**Affiliation**: RWTH Aachen University, Institute of Communication Systems
**Role**: Researcher
**Research Focus**: Multi-channel feedforward active noise control for headphones, reference microphone positioning, diffuse-field filter design.

## Key Contributions

- First author of "Optimal Microphone Positioning for Multi-Channel Feedforward ANC Headphones" (DAGA 2022) — causality-aware MSE time-domain cost function and greedy microphone selection on a 12-microphone Bose QC25, showing ~9 dB active-gain headroom from ipsilateral reference placement — [[sources/forster-2022-optimal-microphone-positioning|Forster 2022]]
