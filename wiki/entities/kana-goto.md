# Kana Goto

**Affiliation**: University of Tsukuba, Japan
**Role**: Researcher
**Research Focus**: Multichannel speech enhancement, blind source separation, geometrically constrained IVA, computationally efficient optimization.

## Key Contributions

- First author of "Accelerating Online Algorithm Using Geometrically Constrained Independent Vector Analysis with Iterative Source Steering" (APSIPA ASC 2022) — online GC-AuxIVA-ISS, an inverse-free online algorithm for geometrically constrained IVA, plus MUSIC-based interference DOA estimation — [[sources/goto-2022-iss-gciva|Goto et al. 2022]]
- First author of "Geometrically Constrained Independent Vector Analysis with Auxiliary Function Approach and Iterative Source Steering" (EUSIPCO 2022) — the offline GC-AuxIVA-ISS predecessor, achieving comparable enhancement to GC-AuxIVA-VCD with 35–50% execution-time reduction (referenced as prior work in [[sources/goto-2022-iss-gciva|Goto et al. 2022]])
