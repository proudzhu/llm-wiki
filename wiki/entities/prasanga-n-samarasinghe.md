# Prasanga N. Samarasinghe

**Affiliation**: Audio and Acoustic Signal Processing Group, The Australian National University, Australia
**Role**: Researcher
**Research Focus**: Active noise control, soundfield estimation, physics-informed neural networks, head-related transfer functions, spherical microphone arrays, relative transfer matrices

## Key Contributions

- Co-authored "Acoustic Feedback Path Mitigation for Multichannel ANC" (EUSIPCO 2026) — [[sources/zhang-2026-feedback-path-mitigation-mcanc|Zhang 2026]]: relative transfer matrix estimation for multichannel ANC feedback mitigation
- Co-authored the Relative Transfer Matrix generalization from RTF to matrices for multiple sources and multichannel microphones (EUSIPCO 2023)
- PINN-based soundfield interpolation for ANC (ICASSP 2024)
- Sound field estimation around a rigid sphere with PINN (arXiv 2023)
- PINN for head-related transfer function upsampling (arXiv 2023)
- SH-domain feedforward ANC using sparse decomposition (IEEE/ACM TASLP 2020)
- Active noise control over 3D space with RMT in the wave domain (WASPAA 2021)
