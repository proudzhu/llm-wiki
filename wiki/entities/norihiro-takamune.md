# Norihiro Takamune

**Affiliation**: The University of Tokyo, Japan
**Role**: Researcher
**Research Focus**: Blind source separation, multichannel signal processing, independent vector analysis, microphone arrays.

## Key Contributions

- Co-authored Distributed FastMNMF with block-diagonal SCMs for distributed microphone arrays (arXiv 2026)
- Auxiliary-function-based decentralized independent vector analysis for distributed microphone arrays (APSIPA ASC 2025)
- Co-authored "Real-Time Speech Extraction Based on Rank-Constrained Spatial Covariance Matrix Estimation and Spatially Regularized Independent Low-Rank Matrix Analysis With Fast Demixing Matrix Estimation" (IEEE Access, 2025) — [[sources/ishikawa-2025-real-time-speech-extraction|Ishikawa et al. 2025: Real-Time RCSCME-based Speech Extraction]]. Contributed to the blockwise batch real-time framework and the FastVCD / FastIP demixing-update algorithms.
