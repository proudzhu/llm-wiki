# Thushara D. Abhayapala

**Affiliation**: Audio and Acoustic Signal Processing Group, The Australian National University, Australia
**Role**: Professor / Group Leader
**Research Focus**: Spatial audio, soundfield reproduction, active noise control, spherical microphone arrays, head-related transfer functions, acoustic signal processing, relative transfer matrices

## Key Contributions

- Co-authored "Acoustic Feedback Path Mitigation for Multichannel ANC" (EUSIPCO 2026) — [[sources/zhang-2026-feedback-path-mitigation-mcanc|Zhang 2026]]: applies the Relative Transfer Matrix framework with covariance subtraction to multichannel acoustic-feedback neutralization
- Originator of the Relative Transfer Matrix generalization from RTF to matrices for multiple sources and multichannel microphones (EUSIPCO 2023)
- PINN-based soundfield interpolation for ANC (ICASSP 2024)
- SH-domain feedforward ANC using sparse decomposition (IEEE/ACM TASLP 2020)
- Active noise control over 3D space with RMT in the wave domain (WASPAA 2021)
- Theory and design of compact hybrid microphone arrays for 3D soundfield analysis (JASA 2015)
- Head-related transfer function upsampling with PINN (arXiv 2023)
- Reproduction of plane-wave soundfield using loudspeaker arrays (IEEE TSAP 2001)
- Active control of outgoing broadband noise fields in rooms (IEEE/ACM TASLP 2019)
