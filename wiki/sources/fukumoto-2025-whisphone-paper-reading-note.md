## 一、问题定义：AI 时代的声音泄漏

LLM 和生成式 AI 正在将人机交互从"操作机器"转变为"对话伙伴"。语音交互将成为主流，但一个核心矛盾始终存在：

**语音输入必然产生声音泄漏**——不仅打扰周围的人，还涉及隐私和信息泄露风险。

想象一下：在办公室或拥挤的街道上大声对着设备说话，既不优雅也不私密。

### 现有方案对比

| 类别 | 代表技术 | 优势 | 局限 |
|------|---------|------|------|
| **完全无声** | EMG 电极 [28]、超声波传感器 [13]、脑电波 [4] | 零泄漏 | 需要个体化训练、识别范围有限、实时性差 |
| **微弱声音（耳语）** | NAM [12]、SilentVoice [11]、WhisperMask [5] | 信号接近正常语音、识别率高 | 需要靠近麦克风、外观不自然 |
| **骨传导麦克风** | 喉麦 [22]、耳道内麦克风 [20] | 抗外部噪声 | 高频衰减严重、仅限高噪声场景 |

Whisphone 的定位很巧妙：**利用人人都能接受的 TWS 耳机形态 + 耳语输入 + 骨传导拾音 + ANC 降噪**，实现日常场景下的私密语音输入。

## 二、核心原理：耳道闭塞效应

### 2.1 骨传导的两条路径

骨传导听声音并非只有"颅骨→耳蜗"一条路。还有一条常被忽视的路径：

> **外耳道辐射（Ear Canal Radiation）**：发声时颅骨和软组织振动 → 外耳道壁振动 → 耳道内辐射声波 → 鼓膜 → 听到声音

研究表明，对于听力正常的人，这条路径对骨传导听觉的贡献**相当大** [25]。

### 2.2 耳道闭塞效应（Occlusion Effect）

当外耳道口被手指或耳塞堵住时，骨传导的**低频成分（<1kHz）会被放大 5-20dB** [8]。原因很简单：辐射到耳道内的声能无法从耳道口逸出，被"困"在里面了。

**Whisphone 的核心洞察**：既然闭塞效应能放大我们自己说话时的骨传导反馈，那耳语这种微弱声音也应该能被放大——只需要在耳道内放一个麦克风。

### 2.3 为什么需要 ANC？

耳语音量约 40dB(A)，远低于正常说话的 60dB(A)。即使有闭塞效应的放大和耳塞的物理隔音，在高噪声环境下信噪比仍然不够。

好消息是：TWS 耳机 ANC 技术近年进步巨大，很多产品标称降噪超过 45dB。**把 ANC 用于麦克风端的噪声抑制**（而非仅仅是播放端的降噪），是 Whisphone 能工作的关键。

## 三、系统设计

### 3.1 硬件配置

```
┌──────────────────────────────────────┐
│         外部噪声 (最高 80dB(A))        │
│                                      │
│   ┌────────────┐                     │
│   │  ANC 耳塞   │ ← 物理密封耳道       │
│   │  (密封)     │ ← ANC 降噪 ~30dB    │
│   │            │                     │
│   │  🎤 MEMS   │ ← 耳道内拾音         │
│   │  麦克风     │   (骨传导耳语)       │
│   └────────────┘                     │
│          ↑                           │
│   耳语 → 骨传导 → 耳道壁辐射            │
└──────────────────────────────────────┘
```

关键设计：
- **麦克风位置**：耳塞尖端，直接对准耳道内部
- **耳塞类型**：密闭式 canal-type（入耳式），物理密封耳道口
- **ANC 功能**：开启后进一步降低外部噪声 ~30dB

### 3.2 三种实现形态

| 类型 | 实现 | 降噪能力 | 适用场景 |
|------|------|---------|---------|
| **有线 USB** | MEMS 麦克风 + 商用 ANC 耳塞 + USB 音频接口 | ~30dB | 实验验证 |
| **蓝牙单耳** | 商用蓝牙耳机改造（拆掉 ECM，接耳道内麦克风） | ~30dB | 日常使用 |
| **TWS 完全无线** | 复用 ANC 耳机的 Feedback 麦克风（重新固件） | ~10dB（PineBuds Pro） | 量产方向 |

**关键洞察**：很多 ANC TWS 耳机已经在耳塞尖端安装了 Feedback 麦克风（用于 ANC 反馈控制）。只需要通过固件重新编程，将这个麦克风优先作为主拾音通道，就能把现有 ANC 耳机"变"成 Whisphone——**零硬件成本**。

## 四、实验结果

### 4.1 拾音性能验证

实验条件：
- 受试者：1 名成年男性
- 耳语音量：40dB(A)（距 1 米测量）
- 背景噪声：安静环境 33dB(A) / 60dB(A) / 80dB(A)（火车站台录音校准）
- 测试语句："こんにちは、私の声が聞こえますか？"

**结果（a）：闭塞效应的信号放大**

| 条件 | 噪声裕度 | 说明 |
|------|---------|------|
| 耳外麦克风 + 耳语 + 无 ANC | ~10dB | 传统耳机方案，裕度不足 |
| **耳道内麦克风 + 耳语 + 无 ANC** | **~20dB（<1.5kHz）** | 闭塞效应放大 ~10dB |

耳道内麦克风在 1.5kHz 以下提供额外 20dB 噪声裕度，其中约 10dB 来自闭塞效应的信号放大。但 2kHz 以上高频快速衰减，4.5kHz 以上几乎无信号。

**结果（b）：ANC 降噪效果**

| 外部噪声 | ANC 关闭 | ANC 开启 | 降噪量 |
|---------|---------|---------|--------|
| 60dB(A) | 60dB(A) | ~30dB(A) | **~30dB** |
| 80dB(A) | 80dB(A) | ~50dB(A) | **~30dB** |

ANC 在两种噪声水平下均提供约 30dB 降噪。

**结果（c）：最终信噪比**

| 外部噪声 | 信噪比改善 | 说明 |
|---------|-----------|------|
| 60dB(A) | **+40dB**（从 -20dB 到 +20dB） | 信号 +10dB + 噪声 -30dB |
| 80dB(A) | **~40dB**（噪声裕度减小） | 仍可用，但已达极限 |

**关键结论**：Whisphone 的总 S/N 改善 = **闭塞效应信号放大（+10dB）+ ANC 降噪（-30dB）= 40dB**。

### 4.2 语音识别性能

测试设置：
- 识别系统：Google Voice Search、OpenAI Whisper（large-v3）
- 测试语句：15 条日语常用语音助手指令
- **无额外训练、无个性化适配**

| 噪声水平 | Google Voice Search WER | OpenAI Whisper WER | 结论 |
|---------|------------------------|-------------------|------|
| Quiet (33dB) | <5% | <5% | 优秀 |
| 60dB(A) | <10% | <10% | 可用 |
| 70dB(A) | <10% | <10% | 可用 |
| **80dB(A)** | **<10%** | **<10%** | **可用（极限）** |
| 90dB(A) | >>50% | >>50% | **不可用**（VAD 频繁失败） |
| 正常语音 80dB+ | <10% | <5% | 正常语音仍可用 |

**关键发现**：
1. **80dB(A) 是 Whisphone 耳语识别的上限**（相当于火车车厢内噪声）
2. 超过 80dB(A) 时，切换到正常语音（60dB(A)）仍可保持低 WER
3. 正常语音 60dB(A) 在 80dB(A) 环境下对周围人几乎不可闻，仍保有一定私密性
4. **无需任何额外训练**——直接使用通用 ASR 引擎即可

## 五、讨论与扩展

### 5.1 回声消除

当 Whisphone 同时用于播放和输入时，播放的音乐/语音会被耳道内麦克风拾取。由于播放信号是已知的，标准回声消除技术（AEC）可以解决此问题。

简单方案：通话时一侧耳机做麦克风、另一侧做听筒（已在 TWS 实现中应用）。

### 5.2 双重噪声抑制

在有人声背景的环境中，某些词汇仍可能干扰识别器。解决方案：

**比较内外麦克风音量**：
- 外部麦克风（ANC 的 FeedForward 麦克风）
- 内部麦克风（ANC 的 Feedback 麦克风 / Whisphone 麦克风）

只允许内部麦克风音量 **高于** 外部麦克风的成分通过——因为耳道物理密封后，外部噪声在耳道内一定比外面小。

### 5.3 单耳 vs 双耳

| 佩戴方式 | 优势 | 局限 |
|---------|------|------|
| 单耳 | 佩戴负担小、可感知外部声音 | 无 |
| 双耳 | 高噪声环境下耳语音调控制更好 | 佩戴负担增加 |

理论上双耳合并可提升 S/N 比 ~1.4 倍，但受限于 TWS 时序同步困难和左右声道相关性降低。

### 5.4 提高识别率

**核心挑战**：骨传导耳语在 2kHz 以上高频成分严重缺失，导致某些辅音（/s/、/h/）和元音（/i/）听起来与正常耳语不同。

解决路径：
1. **最优解**：用骨传导耳语数据重新训练 ASR（但数据收集困难）
2. **替代方案**：用 2kHz 低通滤波器处理现有正常耳语数据集，模拟骨传导数据
3. **利用低频成分**：图 5(a) 显示耳道形变产生的低频尖峰信号包含发音动作信息——将其纳入训练可能进一步提升识别率

### 5.5 超越语音的应用

图 5(b) 展示了 Whisphone 捕捉到的非语音信号：

| 信号 | 内容 | 应用 |
|------|------|------|
| **眨眼** | 耳道压力变化 | 隐蔽控制命令 |
| **舌头敲击上颚** | 节奏信号 | 免唤醒触发器 |
| **鼓腮** | 低频波形 | 手势识别 |
| **心跳** | 微弱周期信号 | 基础心率监测 |

这些亚听觉（sub-audible）成分可用于**免唤醒、低功率、高隐私**的触发命令。作者已在 TWS 实现中实现了节奏命令触发 AI 助手激活。

### 5.6 语言适用性

| 语言类型 | 适用性 | 原因 |
|---------|--------|------|
| 日语、韩语（CV 型） | ✅ 适合 | 以元音为主，声调变化少 |
| 英语 | ⚠️ 部分受限 | 1kHz 以上高频辅音主导，骨传导缺失严重 |
| 中文普通话 | ⚠️ 部分受限 | 声调语言，耳语无声调信息 |

实验中英语 WER：Google 55.0%、Whisper 56.2%（安静环境），远高于日语表现。

## 六、局限与开放问题

1. **高频信息丢失**：2kHz 以上快速衰减，英语等高频辅音丰富的语言识别率差
2. **声调信息丢失**：耳语无声带振动，声调语言（中文）面临额外挑战
3. **噪声上限 80dB(A)**：地铁车厢（90dB+）内耳语不可用
4. **个体差异**：耳道形状、发声方式（声门/唇/硬腭）影响信号质量
5. **全天佩戴的舒适度**：高气密性耳塞导致心跳感知、自声过响等问题——可能需要主动通风机制 [23]

## 七、Q&A

**Q1: Whisphone 和现有骨传导耳机有什么本质区别？**

传统骨传导耳机拾取的是**正常说话**通过颅骨传播的声音，主要用于高噪声环境（如飞行员的通话系统）。Whisphone 的创新在于：
1. 专门针对**耳语**（40dB(A)）设计，而非正常语音（60dB(A)）
2. 利用**耳道闭塞效应**放大信号（+10dB）
3. 结合 **ANC** 抑制外部噪声（-30dB）
4. 形态是**人人都接受的 TWS 耳机**

**Q2: 为什么不直接用现有的 ANC 耳机打电话？**

现有 ANC 耳机打电话时主要依赖外部波束成形麦克风拾取**正常说话**的声音。Whisphone 的不同在于：
- 输入方式是**耳语**而非正常说话
- 麦克风在**耳道内部**而非外部
- 利用的是**骨传导辐射**而非空气传导
- 目的是**私密输入**而非通话

**Q3: Whisphone 能否与 LLM 语音助手直接整合？**

完全可以。作者演示了用 Google Voice Search 和 OpenAI Whisper 直接识别 Whisphone 的耳语输入（无需额外训练）。这意味着任何支持 Whisper 的 LLM 语音接口都可以直接与 Whisphone 整合——用户在任何环境下（办公室、图书馆、火车上）都可以私密地与 AI 助手对话。
